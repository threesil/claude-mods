# Claw HUD

A Claude Code mod that keeps your tasks in view.

- **Task band** above the prompt: overdue count in red, due-today in yellow, and your next task.
- **`/hud` pane**: type a task and press Enter to add it; press its number to tick it off. Done tasks move to the Done section with today's date.
- Reads and writes the same `TASKS.md` as the Claw skill, so Claude, the pane and other sessions stay in sync.

Settings (`/config`): Claw folder, show task band.

Requires Claude Code v2.1.287 or later. Works in the terminal and the Code tab of Claude Desktop. Tested with v2.1.288.
