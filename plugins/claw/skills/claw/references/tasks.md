# Tasks and reminders

## Storage

Tasks live in `TASKS.md` (same location as memory), in this format:

```
## Open
- [ ] Send quote to Baker — due 2026-10-08 — priority high
- [ ] Cancel insurance — no deadline

## Waiting on others
- [ ] Reply from Jan about the schedule — since 2026-10-01

## Done (last 14 days)
- [x] Tax return — 2026-10-02
```

Remove items older than 14 days from "Done" (they stay findable in the journal).

## Reminders with a specific time

A task with a concrete moment ("remind me tomorrow at 10 to...") is more than a note: also put it on the calendar so a real notification fires.

- Phone app with alarm/calendar tools: use the device's calendar tool (or an alarm for a fixed daily reminder, such as medication).
- Google Calendar (or other calendar) connector: create an event with a notification.
- Check the current date, time and time zone first.
- Confirm in one line: "⏰ Tomorrow 10:00: call the dentist."

## Recognizing tasks

Spot tasks even when they aren't called that: "I still need to...", "don't forget to...", an email with a request or deadline. Then ask "Shall I add that as a task?", or add it straight away if SOUL.md says to.

## Giving an overview

For "what do I still need to do": overdue first, then today, then this week, then the rest. At most ~10 lines; offer to show the rest.
